# 🪐 Solar System: Basic LaTeX & Inkscape Practice

This folder demonstrates the fundamental document creation principles covered in the class using LaTeX. 

## 📝 About the Project
The primary objective of this practice was to learn how to structure, format, and compile a basic text document in a professional typesetting environment. 

As part of the assignment:
* An original vector graphic was designed and exported using **Inkscape**.
* The visual was then integrated into a **LaTeX** environment.
* Finally, an informative article about the Solar System was formatted and compiled into a cohesive PDF document.

## 🛠️ Tools Used
* **LaTeX:** For document structuring and typesetting.
* **Inkscape:** For creating and exporting the integrated vector graphics.
