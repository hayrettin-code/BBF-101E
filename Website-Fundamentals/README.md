## 📝 About the Project
This project demonstrates the core building blocks of modern web design. It is a single-page interactive application that showcases HTML structuring, external CSS styling, and JavaScript-based DOM manipulation. 

**Key Features of This Project:**
* **Dynamic Interactivity:** Implemented JavaScript event listeners (`onload`, `onresize`, `onkeydown`) to dynamically change background colors based on user interactions.
* **JavaScript Logic:** Created custom functions for button state management, alert triggers, and color cycling algorithms.
* **Data Structuring:** Utilized semantic HTML to organize complex data, including nested lists (course schedules) and data tables (bee taxonomy).
* **Asset Integration:** Successfully linked external CSS stylesheets and integrated image assets into the page structure.

## 🛠️ Technologies Used
* **HTML5:** Semantic structuring, forms, and embedded media.
* **CSS3:** External styling, text formatting, and hover effects.
* **JavaScript (Vanilla):** Event handling and DOM manipulation.
